# 🎮 미니게임 채팅 (minigame-chat)

친구와 **방 코드 하나로** 접속해서 채팅하며 미니게임을 즐기는 Windows 프로그램입니다.
설치 없이 `minigame_gui.exe` 파일 하나만 있으면 되고, IP 주소나 공유기 설정(포트 포워딩)이 필요 없습니다.

- **1:1 방**: 가위바위보 · 주사위 · 틱택토 · 오목 · 윷놀이 · 실시간 격투 대전 · 숫자야구 · 업다운
- **단체 방 (최대 8명)**: 위 게임을 **모두** 단체로!
  - 다 같이: 끝말잇기 · 가위바위보 · 주사위 · 업다운
  - 2인 대결: 틱택토 · 오목 · 윷놀이 · 격투 (방 안에서 상대를 골라 대결 신청, 결과는 방 전체에 공개)
  - 모든 게임의 승리가 **공동 점수판**에 쌓입니다
- 외부 라이브러리 없이 **C++ / Win32 API / Winsock** 만으로 작성 (소스 파일 1개)

## 파일 구성
| 파일 | 설명 |
|---|---|
| `minigame_gui.cpp` | 전체 소스 코드 |
| `minigame_gui.rc` | 끝말잇기 사전을 exe 안에 넣는 리소스 파일 |
| `data/korean_nouns.txt` | 끝말잇기 사전 (표준국어대사전 명사 192,822개, CC0) |
| `data/korean_nouns_LICENSE.txt` | 사전 데이터의 원본 라이선스 (CC0 1.0) |
| `minigame_gui.exe` | 실행 파일 (사전 포함, 바로 실행 가능) |
| `build.bat` | 소스를 다시 컴파일하는 스크립트 (Visual Studio 필요) |
| `LICENSE` | MIT 라이선스 |
| `README.md` | 이 설명서 |

## 실행 방법
### 1:1 방
1. 한 사람: 닉네임 입력 → **1:1 방 만들기** → `1K7F3Q` 같은 방 코드가 나옵니다 (자동으로 복사됨)
2. 코드를 친구에게 보냅니다
3. 친구: 닉네임 → 방 코드 입력 → **코드로 참가**
4. 위쪽 버튼으로 게임을 골라 함께 플레이

### 단체 방 (최대 8명)
1. 방장: 닉네임 입력 → **단체 방 (최대 8명)** → `AK7F3Q` 같은 방 코드가 나옵니다
2. 친구들: 방 코드 입력 → **코드로 참가** (1:1 방과 같은 칸에 입력하면 자동으로 구분됩니다)
3. 위쪽 탭에서 게임 선택
   - **끝말잇기 · 가위바위보 · 주사위 · 업다운**: 방 전체가 함께 합니다
   - **틱택토 · 오목 · 윷놀이 · 격투**: 탭을 누르면 참가자 목록이 나옵니다. 상대를 클릭해 대결을 신청하고, 상대가 **수락**하면 둘이 대결합니다
   - 대결 중인 상대와는 2인 게임을 자유롭게 오갈 수 있고, 아래 **대결 끝내기** 버튼으로 끝냅니다

### 같은 와이파이라면
아래쪽 **IP로 방 만들기 / IP로 참가**로 중계 서버 없이 직접 연결할 수도 있습니다 (1:1 방만 가능, 방화벽 창이 뜨면 허용).

> 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요. 서명이 없는 개인 제작 프로그램이라 뜨는 창입니다.

## 게임 설명
| 게임 | 1:1 방 | 단체 방 | 방법 |
|---|---|---|---|
| 가위바위보 | ✔ | 다 같이 | 모두 내면 공개. 단체는 손 모양이 2가지만 나왔을 때 이긴 쪽 전원 +10점 |
| 주사위 | ✔ | 다 같이 | 주사위 2개 합이 가장 큰 사람 승리 (+10점) |
| 업다운 | `/ud` 명령 | 다 같이 | 한 명이 1~100 출제, 나머지가 채팅창에 숫자 입력. 먼저 맞힌 사람 +10점 |
| 끝말잇기 | — | 다 같이 | 차례가 되면 채팅창에 단어 입력. 제한 시간 안에 못 내면 탈락, 마지막 1명 우승 |
| 틱택토 | ✔ | 2인 대결 | 3×3 칸에 먼저 한 줄을 만들면 승리 |
| 오목 | ✔ | 2인 대결 | 15×15 판, 5목을 먼저 만들면 승리. 시작한 사람이 흑(선공), 기권 가능 |
| 윷놀이 | ✔ | 2인 대결 | 말 4개, 윷 던지기 → 결과 선택 → 말 이동. 업기·잡기·지름길 지원 |
| 격투 대전 | ✔ | 2인 대결 | 실시간 대전. A/D 이동, W 점프, S 방어, J 펀치, K 발차기 (게임 화면을 클릭해야 조작됨) |
| 숫자야구 | `/bb` 명령 | 대결 중 `/bb` | `/bb` → `/secret 123` → `/g 456` |

단체 방에서 2인 대결에 이기면 +20점이며, 결과는 방 전체 채팅에 알려집니다.

### 끝말잇기 규칙
- 앞 단어의 끝 글자로 시작하는 2글자 이상 한글 단어 (두음법칙 허용: 력 → 역, 라 → 나)
- **표준국어대사전에 있는 명사만 인정** (약 19만 개, exe에 내장). 사전에 없으면 "사전에 없는 단어예요"로 거절되며 시간 안에 다시 낼 수 있습니다
- 이미 나온 단어는 사용할 수 없음
- 점수: 단어 글자 수 × 10점, 우승 +50점
- 제한 시간은 15초에서 시작해 단어가 이어질수록 줄어듭니다 (최소 6초)
- 사전 데이터는 대부분 2~4글자 단어라서, "아이스크림"처럼 긴 외래어는 없을 수 있습니다

## 동작 원리
```
 [내 PC] ──TCP──▶ 공개 MQTT 중계 서버 ◀──TCP── [친구 PC들]
                (broker.emqx.io 등)
```
- 모든 PC가 인터넷의 공개 MQTT 서버로 **밖으로 나가는 연결**만 하므로 공유기 설정이 필요 없습니다.
- 방 코드 = 서버 위의 대화 채널 이름입니다. 첫 글자로 방 종류(숫자 = 1:1, 영문 = 단체)와 사용할 서버를 구분합니다.
- MQTT 3.1.1 프로토콜(CONNECT, SUBSCRIBE, PUBLISH, PING, Last Will)을 라이브러리 없이 직접 구현했습니다.
- 갑자기 연결이 끊기면 서버가 "나갔음" 메시지를 대신 보내줍니다 (Last Will 기능).
- **1:1 게임**: 두 프로그램이 같은 규칙으로 동시에 계산합니다. 무작위 값(윷, 주사위)은 던진 쪽이 정해서 보냅니다.
- **단체 방**: 모든 메시지에 보낸 사람 ID를 붙여 방 전체에 보냅니다.
  - 방장 프로그램이 심판입니다. 참가자 명단, 공동 점수판, 끝말잇기의 단어 검사·제한 시간·탈락을 판정해 모두에게 알립니다.
  - 다 같이 하는 가위바위보·주사위는 모두의 선택이 모이면 각 프로그램이 같은 규칙으로 결과를 계산합니다.
  - 2인 대결은 신청 → 수락으로 짝이 정해지면, 그 둘의 게임 메시지만 서로 처리합니다. (1:1 방과 같은 게임 코드를 그대로 재사용)
- **격투**: 초당 약 30번 위치를 주고받고, 상대 움직임은 보간해서 부드럽게 그립니다.

## 직접 빌드하기
Visual Studio(C++ 데스크톱 개발)를 설치한 뒤 `build.bat`을 실행하면 `minigame_gui.exe`가 만들어집니다.
```
rc /fo minigame_gui.res minigame_gui.rc
cl /EHsc /utf-8 /O2 /std:c++17 minigame_gui.cpp minigame_gui.res /link /SUBSYSTEM:WINDOWS
```
(`minigame_gui.res` 없이 빌드하면 사전 검사만 빠지고 나머지는 그대로 동작합니다.)

## 주의 사항
- 공개 중계 서버를 사용하므로 **방 코드를 아는 사람은 이론상 대화 내용을 볼 수 있습니다.** 민감한 내용은 채팅하지 마세요.
- 공개 서버가 점검 중이면 연결이 안 될 수 있습니다. 잠시 후 다시 시도하세요.

## 사용한 기술 · 오픈소스
- 코드: 외부 오픈소스 라이브러리 없이 Windows 기본 API (Win32, GDI, Winsock)와 C++ 표준 라이브러리만 사용합니다.
- 데이터: **[pd-korean-noun-list-for-wordles](https://github.com/han-dle/pd-korean-noun-list-for-wordles)** v0.4.0 (CC0 1.0)
  - 국립국어원 표준국어대사전의 명사를 정리한 오픈소스 단어 목록입니다 (2018-11-13 수집, 원본: [korean-word-game/db](https://github.com/korean-word-game/db)).
  - 이 중 2글자 이상 단어 192,822개를 `data/korean_nouns.txt`로 옮겨 끝말잇기 단어 검사에 사용합니다. 원본 라이선스는 `data/korean_nouns_LICENSE.txt`에 있습니다.
- 중계 서버: [EMQX 공개 브로커](https://www.emqx.com/en/mqtt/public-mqtt5-broker), [HiveMQ 공개 브로커](https://www.hivemq.com/mqtt/public-mqtt-broker/) (외부 서비스로 접속만 함)
