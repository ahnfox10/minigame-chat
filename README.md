# 🎮 미니게임 파티 (minigame-chat)

친구들과 **방 코드 하나로** 모여서 채팅하며 미니게임을 즐기는 Windows 프로그램입니다.
설치 없이 `minigame_gui.exe` 파일 하나만 있으면 되고, 회원가입이나 공유기 설정(포트 포워딩)이 필요 없습니다.

- **한 방에 2~8명**. 방 안에서 채팅하면서 원하는 게임을 골라 함께 합니다
  - 방 전체가 함께: **끝말잇기 · 가위바위보**
  - 초대해서 함께: **오목(2명) · 윷놀이(2~4명) · 격투(2~4명 난투) · 레이싱(2~8명) · 페인트볼 FPS(2~8명)**
  - 초대할 때 **여러 명을 한 번에 선택**할 수 있고, 수락한 사람들끼리 바로 시작합니다
  - 모든 게임의 승리가 **공동 점수판**에 쌓입니다
- **꾸미기**: 플레이어마다 색과 머리 장식을 고르면 돌 · 말 · 캐릭터 · 자동차 · 채팅 이름에 반영되어 친구들 화면에도 보입니다. 오목판 · 윷판 · 레이싱 코스는 테마(나무 · 밤하늘 · 벚꽃 · 민트)를 고를 수 있습니다
- 외부 라이브러리 없이 **C++ / Win32 API(GDI) / Winsock** 만으로 작성 (소스 파일 1개). 3D처럼 보이는 페인트볼 화면도 레이캐스팅을 직접 구현해 GDI로 그립니다

| `data/extra_words.txt` | 어인정 단어 (사전에 없지만 다들 아는 말 353개. 팀이 직접 적었고, 줄을 더해 늘릴 수 있음) |

| `README.md` | 이 설명서 |

## 실행 방법
1. 방장: 닉네임 입력 → **방 만들기 (2~8명)** → `AK7F3Q` 같은 방 코드가 나옵니다 (자동으로 복사됨)
2. 코드를 친구들에게 보냅니다 (아래 **코드 복사** 버튼으로 다시 복사 가능)
3. 친구들: 닉네임 → 방 코드 입력 → **코드로 참가**
4. 위쪽 탭에서 게임 선택
   - **끝말잇기 · 가위바위보**: 방 전체가 함께 합니다
   - **오목 · 윷놀이 · 격투 · 레이싱 · 페인트볼**: 탭을 누르면 참가자 목록이 나옵니다. 함께 할 사람을 **여러 명 선택**(또는 **전체 선택**)하고 **초대 보내기**를 누르면, 초대받은 사람 화면에 수락/거절 창이 뜹니다. 모두 응답하면 자동으로 시작하고, 기다리지 않고 **지금 시작**을 눌러 수락한 사람들끼리 먼저 시작할 수도 있습니다
   - 한 방에서 여러 대결이 동시에 진행될 수 있습니다. 판이 끝나면 초대한 사람이 **다시 하기**를 누를 수 있고, 아래 **대결 나가기** 버튼으로 나옵니다

### 꾸미기
오른쪽 위 **꾸미기** 버튼 (메인 화면과 방 안 모두에서 가능)
- **내 색** 8가지, **머리 장식** 6가지 (없음 · 머리띠 · 왕관 · 고깔 · 고양이 귀 · 뿔), **윷놀이 말 모양** 6가지 (동글 · 별 · 하트 · 보석 · 고양이 · 내 얼굴) — 친구들 화면에도 보입니다
- **게임 판 테마** 4가지 — 내 화면에만 적용됩니다
- 닉네임과 꾸미기 설정은 PC에 저장되어 다음에 켤 때 그대로입니다

### 화면 조작
- **전체 화면**: `F11` 또는 오른쪽 위 **전체 화면** 버튼 (다시 누르거나 `Esc`로 창 모드). 화면 크기에 맞춰 게임 · 채팅 · 글자가 함께 커집니다
- **◀ 메인**: 방에서 나가 처음 화면으로 돌아갑니다 (접속 중이면 취소). 방장이 나가면 방이 닫힙니다
- `Enter` = 채팅 입력, `Esc` = 게임 화면으로 (키보드로 조작하는 게임은 게임 화면을 클릭해야 조작됩니다)

### 같은 와이파이라면 (인터넷 없이도)
아래쪽 **IP로 방 만들기 / IP로 참가**로 중계 서버 없이 직접 연결할 수 있습니다. 방장 PC가 참가자들의 메시지를 서로에게 전달해 주므로 IP 방에서도 8명까지 모든 게임을 할 수 있습니다 (방화벽 창이 뜨면 허용).

> 처음 실행할 때 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누르세요. 서명이 없는 개인 제작 프로그램이라 뜨는 창입니다.

## 게임 설명
| 게임 | 인원 | 방법 |
|---|---|---|
| 끝말잇기 | 방 전체 | 차례가 되면 채팅창에 단어 입력. 제한 시간 안에 못 내면 탈락, 마지막 1명 우승 |
| 가위바위보 | 방 전체 | 모두 내면 "가위! 바위! 보!" 하고 주먹을 흔든 뒤 한꺼번에 공개. 손 모양이 2가지만 나왔을 때 이긴 쪽 전원 +10점 |
| 오목 | 2명 | 15×15 판, 5목을 먼저 만들면 승리. 돌은 각자 고른 색, 기권 가능 |
| 윷놀이 | 2~4명 | 윷 던지기(윷가락이 빙글빙글 돌며 날아감) → 결과 선택 → 말 이동(한 칸씩 뛰어감, 잡힌 말은 대기 자리로 날아감). 업기 · 잡기 · 지름길 지원. 말은 2명 4개 · 3명 3개 · 4명 2개씩 |
| 격투 | 2~4명 | 실시간 난투, 마지막까지 남으면 승리. A/D 이동, W 점프, S 방어, J 펀치, K 발차기 |
| 레이싱 | 2~8명 | 운전석에서 보는 1인칭 서킷 3바퀴 (코스 2종, 오른쪽 위에 미니맵). W 가속, S 브레이크, A/D 방향, Shift 부스터(3번), R 도로로 복귀. 노란 발판을 밟으면 가속, 잔디에서는 감속 |
| 페인트볼 | 2~8명 | 1인칭 미로 슈팅. 게임 화면을 클릭하면 **마우스로 조준**하고 클릭으로 발사 (Esc로 마우스 풀기). W/A/S/D 이동. 키보드만으로도 가능 (←/→ 돌기, Space 발사). 세 번 맞으면 아웃되고 다른 곳에서 다시 시작, 먼저 5번 아웃시키면 승리 |

초대해서 하는 게임에서 이기면 +20점이며, 결과는 방 전체 채팅에 알려집니다.

### 끝말잇기 규칙
- 앞 단어의 끝 글자로 시작하는 2글자 이상 한글 단어 (두음법칙 허용: 력 → 역, 라 → 나)
- **표준국어대사전에 있는 명사만 인정** (약 19만 개, exe에 내장). 사전에 없으면 "사전에 없는 단어예요"로 거절되며 시간 안에 다시 낼 수 있습니다
- 이미 나온 단어는 사용할 수 없음
- **낸 단어의 뜻**이 단어 아래와 채팅창에 함께 나옵니다. 소리가 같은 말이 여럿이면 뜻을 3개까지 보여 줍니다
- 시간 초과로 탈락하면 **낼 수 있었던 단어 하나와 그 뜻**을 모두에게 알려 줍니다. 낼 단어가 사전에 아예 없었다면 그렇게 알려 줍니다
- 방장이 시작 전에 고르는 규칙 두 가지
  - **한방 단어 금지** (처음에는 켜짐): 끝 글자로 시작하는 단어가 사전에 하나도 없는 말(예: 나트륨)은 낼 수 없습니다
  - **어인정 허용** (처음에는 꺼짐): 사전에 없어도 다들 아는 말(게임 · 만화 · 상표 · 새말 등 353개, `data/extra_words.txt`)을 인정합니다
- 점수: 단어 글자 수 × 10점, 우승 +50점
- 제한 시간은 15초에서 시작해 단어가 이어질수록 줄어듭니다 (최소 6초)
- 사전 데이터는 대부분 2~4글자 단어라서, "아이스크림"처럼 긴 외래어는 없을 수 있습니다

## 동작 원리
```
 [내 PC] ──TCP──▶ 공개 MQTT 중계 서버 ◀──TCP── [친구 PC들]
               (broker.hivemq.com 등)
```
- 모든 PC가 인터넷의 공개 MQTT 서버로 **밖으로 나가는 연결**만 하므로 공유기 설정이 필요 없습니다.
- 방 코드 = 서버 위의 대화 채널 이름입니다. 첫 글자(A~C)로 사용할 서버를 구분합니다.
- MQTT 3.1.1 프로토콜(CONNECT, SUBSCRIBE, PUBLISH, PING, Last Will)을 라이브러리 없이 직접 구현했습니다.
- 갑자기 연결이 끊기면 서버가 "나갔음" 메시지를 대신 보내줍니다 (Last Will 기능).
- **메시지 유실 대비**: 공개 서버는 메시지를 가끔 잃어버립니다 (실제로 측정해 보니 한 서버는 한 사람이 초당 10개 넘게 보내면 초과분을 버렸습니다). 그래서
  - 초대 · 차례 · 명중 같은 중요한 메시지에는 번호를 붙여 두 번 더 보내고, 받는 쪽은 번호 순서대로 한 번씩만 처리합니다.
  - 자주 보내는 위치 정보는 잃어도 다음 것이 오므로 그대로 보내고, 느린 서버에서는 보내는 횟수를 줄입니다.
  - 메시지를 버리지 않는 서버를 먼저 시도하고, 버리는 서버는 예비로만 씁니다.
- **방장 프로그램이 심판**: 참가자 명단, 공동 점수판, 끝말잇기의 단어 검사 · 제한 시간 · 탈락을 판정해 모두에게 알립니다.
- **초대해서 하는 게임**: 초대한 사람이 참가자 순서와 난수 씨앗을 정해 알리면, 각 프로그램이 같은 상태에서 시작해 같은 규칙으로 계산합니다. 같은 대결에 있는 사람의 게임 메시지만 처리하므로 한 방에서 여러 대결이 동시에 진행됩니다.
- **실시간 게임 (격투 · 레이싱 · 페인트볼)**: 각자 자기 캐릭터만 계산해서 초당 11~20번 상태를 보내고, 다른 사람은 받은 위치를 향해 부드럽게 보간해서 그립니다. 맞았는지는 때린 쪽이 판정해 알리고, 체력은 맞은 쪽이 관리합니다.
- **페인트볼 화면**: 미로 지도에 화면 세로줄마다 광선을 쏴서(DDA 레이캐스팅) 벽까지의 거리를 구하고, 가까울수록 높게 그려 3D처럼 보이게 합니다. 다른 플레이어는 거리에 맞춰 크기를 줄이고 벽에 가려진 부분은 잘라서 그립니다.
- **레이싱 화면**: 차의 움직임은 평면 지도 위에서 계산하고, 화면만 1인칭으로 그립니다. 도로 · 연석 · 잔디를 미리 칠해 둔 바닥 지도를 화면 줄마다 거리에 맞춰 읽어 원근법으로 펼칩니다 (작은 픽셀 버퍼에 그려서 확대).
- **IP 방**: 방장 PC가 서버 역할을 해서, 참가자에게서 받은 메시지를 다른 참가자들에게 전달합니다.

## 직접 빌드하기
Visual Studio(C++ 데스크톱 개발)를 설치한 뒤 `build.bat`을 실행하면 `minigame_gui.exe`가 만들어집니다.
```
rc /fo minigame_gui.res minigame_gui.rc
cl /EHsc /utf-8 /O2 /std:c++17 minigame_gui.cpp minigame_gui.res /link /SUBSYSTEM:WINDOWS
```
(`minigame_gui.res` 없이 빌드하면 사전 검사만 빠지고 나머지는 그대로 동작합니다.)

## 주의 사항
- 공개 중계 서버를 사용하므로 **방 코드를 아는 사람은 이론상 대화 내용을 볼 수 있습니다.** 민감한 내용은 채팅하지 마세요.
- 공개 서버가 점검 중이면 연결이 안 될 수 있습니다. 잠시 후 다시 시도하거나 IP 방을 이용하세요.
- 방장이 나가면 방이 닫힙니다.
- 이전 버전과는 방을 같이 쓸 수 없습니다. 모두 같은 버전의 exe를 사용하세요.

## 사용한 기술 · 오픈소스
- 코드: 외부 오픈소스 라이브러리 없이 Windows 기본 API (Win32, GDI, Winsock)와 C++ 표준 라이브러리만 사용합니다.
- 데이터: **[pd-korean-noun-list-for-wordles](https://github.com/han-dle/pd-korean-noun-list-for-wordles)** v0.4.0 (CC0 1.0)
  - 국립국어원 표준국어대사전의 명사를 정리한 오픈소스 단어 목록입니다 (2018-11-13 수집, 원본: [korean-word-game/db](https://github.com/korean-word-game/db)).
  - 이 중 2글자 이상 단어 192,822개를 `data/korean_nouns.txt`로 옮겨 끝말잇기 단어 검사에 사용합니다. 원본 라이선스는 `data/korean_nouns_LICENSE.txt`에 있습니다.
- 단어 뜻: **국립국어원 표준국어대사전** ([CC BY-SA 2.0 KR](https://creativecommons.org/licenses/by-sa/2.0/kr/))
  - Hugging Face의 [hac541309/stdict_kor](https://huggingface.co/datasets/hac541309/stdict_kor)에서 받아, 위 단어 목록에 있는 말의 첫 번째 뜻만 짧게 줄여 `data/korean_defs.txt`로 만들었습니다 (만드는 방법: `tools/make_defs.py`).
  - 이 파일(`data/korean_defs.txt`)은 원본과 같은 CC BY-SA 2.0 KR 조건을 따릅니다. 프로그램 코드의 MIT 라이선스와는 따로입니다.
  - 사전 단어의 약 78%에만 뜻이 실려 있고, 소리가 같은 말 가운데 어느 뜻이 흔한지는 짐작으로 골랐기 때문에 낯선 뜻이 먼저 나올 수 있습니다.
